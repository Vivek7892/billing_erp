# Production Deployment Guide: Render + Name.com

This guide covers deploying the Billing ERP application to **Render** using your custom domain **`dreamwithtech.dev`** with:
- **Application Portal:** `https://app.dreamwithtech.dev`
- **Public Bill Share Links:** `https://share.dreamwithtech.dev`
- **Backend API:** `https://billing-system-api.onrender.com` (or optional custom `https://api.dreamwithtech.dev`)

---

## Architecture Overview

1. **Backend Web Service (`billing-system-api`):**
   - Django 4.2 REST Framework running on Gunicorn (`0.0.0.0:$PORT`)
   - PostgreSQL database (Render managed Postgres or Supabase)
   - Dynamic CORS & CSRF support for `app.dreamwithtech.dev` and `share.dreamwithtech.dev`
   - Healthcheck endpoint at `/health/`
   - Automatic migrations during startup via `python start.py`

2. **Frontend Static Site (`billing-system-frontend`):**
   - Vite React Single Page Application (SPA)
   - Built to `dist/` directory
   - Rewrite rule `/*` -> `/index.html` for deep links (`/billing/new`, `/bill/:token`, etc.)
   - Dual custom domains: `app.dreamwithtech.dev` and `share.dreamwithtech.dev`

---

## 1. Deploying to Render via Blueprint

The repository includes a root `render.yaml` Blueprint file.

1. Go to the [Render Dashboard](https://dashboard.render.com/).
2. Click **New +** > **Blueprint**.
3. Connect your Git repository (`billing_erp`).
4. Render will read `render.yaml` and configure:
   - **Web Service:** `billing-system-api`
   - **Static Site:** `billing-system-frontend`
   - **PostgreSQL Database:** `billing-system-db`
5. Click **Apply**.

## 3. Render Build & Start Commands

- **Backend Web Service (`billing-system-api`):**
  - **Root Directory:** `backend`
  - **Build Command:** `pip install -r requirements.txt && python manage.py collectstatic --noinput`
  - **Start Command:** `python start.py`
  - **Health Check Path:** `/health/`

- **Frontend Static Site (`billing-system-frontend`):**
  - **Root Directory:** `frontend`
  - **Build Command:** `npm install && npm run build`
  - **Publish Directory:** `dist`
  - **SPA Rewrite Rule:** Source: `/*`, Destination: `/index.html`

---

## 4. Name.com DNS Configuration

Log in to your **Name.com** account and navigate to **DNS Management** for `dreamwithtech.dev`.

Add the following **CNAME** records:

| Type | Host / Subdomain | Answer / Target / Value | TTL | Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **CNAME** | `app` | `billing-system-frontend.onrender.com` | `300` (or Default) | Main Billing ERP Application |
| **CNAME** | `share` | `billing-system-frontend.onrender.com` | `300` (or Default) | Public Bill & Invoice Sharing |
| **CNAME** *(Optional)* | `api` | `billing-system-api.onrender.com` | `300` (or Default) | Custom API Domain |

*(Note: Replace `billing-system-frontend.onrender.com` and `billing-system-api.onrender.com` with the exact onrender.com hostnames displayed in your Render service settings if different).*

---

## 5. Domain Verification on Render

1. In the Render Dashboard, open your **`billing-system-frontend`** Static Site.
2. Go to **Settings** > **Custom Domains**.
3. Add:
   - `app.dreamwithtech.dev`
   - `share.dreamwithtech.dev`
4. Render will verify the CNAME records from Name.com and automatically issue **Let's Encrypt SSL/TLS certificates** within a few minutes.

- [ ] Open `https://share.dreamwithtech.dev` (root) -> redirects to `https://app.dreamwithtech.dev`.
- [ ] Print A4 and Thermal invoices -> QR codes encode `https://share.dreamwithtech.dev/bill/...`.
